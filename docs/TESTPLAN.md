# COBOL Account Management System — Test Plan

## Scope and execution notes

This plan captures the behavior implemented in `src/cobol/main.cob`, `src/cobol/operations.cob`, and `src/cobol/data.cob`, for stakeholder review and as a baseline for later Node.js unit and integration tests. The program operates on one in-memory balance, initialized to `1000.00`; it does not persist data between program runs or maintain separate accounts.

Run menu cases in a fresh program session unless a case says otherwise. When checking sequences, run the listed actions in the same session and verify each displayed balance. The COBOL fields use `PIC 9(6)V99` (six integer digits and two implied decimal digits). The implied decimal point is not explicitly formatted in the `DISPLAY` statements; capture the actual console representation (which may be an eight-digit value such as `00100000`) and verify its logical monetary value. Amount fields are unsigned and amounts are not checked for positivity. Out-of-range and nonnumeric console input behavior can depend on the COBOL runtime; characterize those cases rather than assuming a result.

“Actual Result” and “Status” are left for the tester to fill in. Use Pass or Fail in Status after execution. Cases marked as characterization or stakeholder decision should not be treated as a confirmed business rule until agreed.
